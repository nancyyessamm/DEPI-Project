# DEPI-Project
A data analysis project including Python, SQL, Excel, and Power BI focused on football performance, IMDb movies, and global water distribution
# Data Analysis Project - Digital Egypt Pioneers Initiative (DEPI)

## Project Description
This project was created as part of the **Digital Egypt Pioneers Initiative** and consists of four main sections, each focusing on different tools and techniques for data analysis.

## Project Sections
### 1. **Football Player Performance Analysis Using Python**
- In this section, we analyzed the performance data of football players during matches using Python.  
- Tools used:  
  - `pandas` for data manipulation and analysis.  
  - `matplotlib` and `seaborn` for data visualization.

### 2. **Movie Analysis from IMDb Using SQL**
- Analyzed a dataset of movies using SQL queries to extract insights such as:  
  - Top-rated movies.  
  - Most popular movie genres.  
  - The relationship between budget and ratings.

### 3. **Global Water Distribution Analysis Using Excel and Power BI**
- This section focused on analyzing global water distribution data to uncover:  
  - Distribution percentages across different countries.  
  - Regions with the highest water scarcity.  
  - Comparisons between various water sources.  
- Tools used:  
  - **Excel** for data cleaning and preparation.  
  - **Power BI** for creating interactive dashboards and reports.

## Requirements
To run this project, ensure the following tools and environments are available:
1. Python 3.x  
   - Required libraries:  
     - `pandas`  
     - `matplotlib`  
     - `seaborn`  

2. SQL-compatible database (SQLite).  
3. Power BI Desktop.  
4. Microsoft Excel or Google Sheets.
